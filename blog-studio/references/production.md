# Visuals, versions and delivery

Decide whether a figure helps explain a mechanism, comparison or spatial relationship. No quota: omit decorative images when unnecessary. Plan at a useful point while drafting, then produce necessary figures once the text is stable. Specify the figure's purpose, placement, factual inputs, labels and accessibility description. Use deterministic plotting or diagram tools with verified data for exact charts and system relationships. An artistic image is not evidence, an exact diagram, or a real screenshot. Label synthetic imagery; never pass a generated image off as a screenshot. A free local diagram or plot can be made within the requested work when tools are available; paid generation and sending material to an external service require separate authorization and any necessary budget approval. If no suitable generation tool is available or authorized, provide clearly marked placeholders or prompts rather than claiming images exist.

Keep the Markdown master intact. Produce formatted or platform-specific copies separately; compare their text with the master to detect accidental edits. Translate in a separate copy, preserve factual meaning and maintain terminology consistently. Export using an available host tool and inspect the actual output when possible; report missing fonts, unsupported formatting, failed rendering or incomplete preview honestly. Never report success for an unverified or failed export.

A local draft, remote draft, and public publication are distinct actions. Ask for explicit permission before remote upload or publishing, and before any paid service obtain budget approval. Don't automatically install dependencies, log in, transmit private source material, or invoke external generators. If those capabilities or permissions are missing, return local Markdown and actionable figure specifications.
